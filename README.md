# Lecture on WTD prepared with Jupyter Book

## 项目简介

整个讲义采用Jupyter Book编写，所以需要安装`jupyter-book`工具。

1. 安装`uv` 工具；
2. 用`uv` 工具建立Python虚拟环境；
3. 利用`jupyter-book`命令编译生成HTML文件。
4. 访问生成的HTML文件。

## 源代码
