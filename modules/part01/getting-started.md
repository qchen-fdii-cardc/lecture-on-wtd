# 讲义内容简介

本章将介绍空气动力学试验、设备的基本概念和入门步骤。您将了解空气动力学试验的定义、目的以及在工程中的应用。此外，我们还将提供一个学习路线图，帮助您系统地掌握相关知识和技能。
通过本章的学习，您将为后续章节的深入内容打下基础。

本讲义应该配合两个主要的参考教材来使用：

- 《高低速风洞气动与结构设计》，中国人民解放军总装备部军事训练教材编审工作委员会编，北京：国防工业出版社，2003年4月，ISBN 7-118-03068-6。
- 《实用流体阻力手册》，华绍曾、杨学宁等编译，北京：国防工业出版社，1985年3月第一版，统一书号 15034·2630。

前者给出实际设计风洞各个部段的重要设计方法和步骤，后者则提供了丰富的经验数据和实用公式，帮助理解风洞部段的阻力特性。当然，本讲义的内容本身可以成为独立的学习材料，只是尽量减少对上述教材的直接引用。

此外，新颁布的GJB 112283系列标准也将作为重要参考资料，确保设计符合最新的行业标准和要求。

- GJB 112283.1-2023《常规风洞设计规范 第1部分：总则》
- GJB 112283.2-2023《常规风洞设计规范 第2部分：总体气动设计》
- GJB 112283.3-2023《常规风洞设计规范 第3部分：结构设计》
