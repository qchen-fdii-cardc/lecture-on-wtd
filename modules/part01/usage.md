# 使用本讲义的最佳实践

本讲义是一份基于Jupyter技术栈编写的交互式文档，推荐的使用方式是：

- 在本地安装Jupyter环境，下载本讲义的源代码，然后在Jupyter Notebook或JupyterLab中打开和运行各个章节的.ipynb文件。
- 使用在线Jupyter服务（如Binder、Google Colab等）打开和运行本讲义的.ipynb文件。

通过这种方式，读者可以直接在文档中运行代码单元，查看结果，并进行修改和实验，从而获得更好的学习体验。

此外，本讲义还可以导出为静态的HTML或PDF格式，供离线阅读和打印使用。但这种方式无法体验交互式功能，建议仅作为辅助阅读手段。

在运行本讲义时，需要安装Python及相关依赖库。推荐使用`uv`环境管理工具创建独立的Python环境，以避免与系统Python或其他项目的依赖冲突；并根据讲义提供的`pyproj.toml`文件安装所需的依赖包。然后运行Jupyter Notebook或JupyterLab，即可打开和运行本讲义的.ipynb文件。

具体的安装和使用步骤，请参考本讲义的相关章节。
