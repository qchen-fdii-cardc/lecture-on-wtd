# 本章内容

本章依据GJB 112283.1-2023《常规风洞设计规范 第1部分：总则》7.2的规定，详细介绍风洞建设项目在立项阶段所需完成的各项论证工作，包括项目建议书、环境影响评估报告、安全评估报告和设计任务书等文件的编制要求和内容要点，确保项目在技术、经济、环境和安全等方面具备充分的可行性基础。

在了解这个总体的概念、程序和要求后，讲义以低速风洞Re数范围为例，介绍风洞设计的参数如何从飞行力学、空气动力学等需求中推导出来，并介绍风洞设计的基本流程和方法，为后续章节的深入学习打下基础。

另外，再给出两个立项论证阶段大概完成的总体气动设计范例，一个是低速直流风洞的主要部件的气动轮廓，一个是稳定段的优化设计初步考虑。
