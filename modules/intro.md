# 前言

本书是使用 Jupyter Book 准备的关于 WTD 的讲义。Jupyter Book 是一个开源工具，可以用来创建包含 Jupyter 笔记本、Markdown 文件和其他内容的交互式电子书和文档。它支持丰富的内容格式，并且可以轻松地将代码与文本结合在一起，适合用于教学材料、技术文档和研究报告等。有关更多信息，请查看 [the Jupyter Book documentation](https://jupyterbook.org)。

讲义按照内容分为五个模块，每个模块包含若干章节。

在这个讲义中，尽量不重复介绍《高低速风洞气动结构设计》一书内容，尽管不可避免在很多地方需要用到该书的内容。讲义对这部分内容只做简要介绍，更多内容请参考该书。

本讲义主要的重点在与新的国军标和数值赋能的方向。具体来说，讲义会对新的设计理念（MBSE）进行重点介绍，特别地，对经典方法地程序化非常注重，所有能够以小规模（数百行量级）的代码实现的内容，都会提供相应的代码示例。就算是用于演示的框图和例图，也会提供相应的Mermaid代码，方便读者理解、修改和重用（系统设计还是需要熟练运用各种图表）。

因此，本讲义不仅适合初学者入门，也适合有一定基础的读者深入学习和实践。学习讲义可以按照顺序进行，也可以根据兴趣选择特定模块和章节进行学习。选择采用 Jupyter Book 作为讲义的载体，旨在利用其交互性和易用性，提升学习体验。讲义编写组尽可能会在讲义中提供代码示例和练习，以帮助读者更好地理解和应用所学内容。

如果在使用过程中遇到任何问题，欢迎通过 GitHub 提交 issue 或 pull request 与我们联系。

## 使用方法

本书的页面，可以下载为PDF或者`ipynb`，后者可以用Jupyter Notebook或者Jupyter Lab来运行，提供更好的交互体验。而利用Jupyter Book生成的网页和PDF并没有交互能力。

为了完整地体验本讲义，请按照第一部分中的相关章节安装软件环境、下载`ipynb`文件，体验计算过程，并自由调节文档中的参数，重新运行代码，观察效果。总之，这样才是本讲义的最佳体验。
