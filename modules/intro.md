# 前言

本书是使用 Jupyter Book 准备的关于 WTD 的讲义。讲义按照内容分为五个模块，每个模块包含若干章节。

## 关于Jupyter Book

Jupyter Book 是一个开源工具，可以用来创建包含 Jupyter 笔记本、Markdown 文件和其他内容的交互式电子书和文档。它支持丰富的内容格式，并且可以轻松地将代码与文本结合在一起，适合用于教学材料、技术文档和研究报告等。有关更多信息，请查看 [the Jupyter Book documentation](https://jupyterbook.org)。

## 使用方法

本书的页面，可以下载为PDF或者`ipynb`，后者可以用Jupyter Notebook或者Jupyter Lab来运行，提供更好的交互体验。而利用Jupyter Book生成的网页和PDF并没有交互能力。

为了完整地体验本讲义，请按照第一部分中的相关章节安装软件环境、下载`ipynb`文件，体验计算过程，并自由调节文档中的参数，重新运行代码，观察效果。总之，这样才是本讲义的最佳体验。
